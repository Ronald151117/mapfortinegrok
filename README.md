# mapfortinegrok

Mapa de El Salvador en 2D y 3D. Las calles son de OpenStreetMap, el relieve es terreno real y el dibujo es de isla colorida: manzanas gruesas, vías amarillas y árboles en San Salvador y La Libertad.

## Uso

Acerca el zoom sobre una ciudad. El mouse mueve, gira e inclina el mapa. El botón de arriba a la izquierda cambia entre 2D y 3D.

```bash
npm install
npm run dev
```
